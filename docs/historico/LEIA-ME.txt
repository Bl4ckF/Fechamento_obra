ORGANIZADOR DO PROJETO ENGELMIG - WINDOWS 10/11 64 BITS

1. Extraia este ZIP.
2. Feche o programa de fechamento de obras.
3. Abra Organizar_Projeto_Engelmig.exe normalmente, sem administrador.
4. Cole o caminho da pasta que contem app.py e INICIAR.bat, se solicitado.
5. Confira a lista. Digite ORGANIZAR para confirmar, ou Enter para cancelar.

O executavel pode ficar dentro ou fora da pasta do projeto. Antes de mover qualquer arquivo, cria um backup dos arquivos envolvidos ao lado da pasta do projeto e confere o conteudo das copias. Se nao puder criar o backup, nao move nada. Essa copia nao e um backup completo das obras.
